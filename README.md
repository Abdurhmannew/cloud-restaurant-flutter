# Cloud Restaurant

A Flutter-based food ordering application developed as a graduation project in Software Engineering.

## Overview

**Cloud Restaurant** is a mobile application designed to provide users with an organized food-ordering experience. The application allows users to browse meals by category, view meal details, add meals to a cart, and manage orders.

The project was developed with a focus on **software engineering practices, system analysis, UI design, application development, and database design**.

## Project Objectives

* Provide an organized food-ordering experience.
* Classify meals into breakfast, lunch, dinner, and healthy food categories.
* Allow users to browse meal details and manage quantities.
* Provide shopping cart and order management features.
* Design a system that can support advanced features such as personalized recommendations and location-based delivery tracking.

## Main Features

### Customer

* Account creation and verification flow.
* User profile management.
* Location and delivery address interface.
* Meal categories and browsing.
* Meal details and quantity selection.
* Shopping cart.
* Order processing and status.
* Invoice and order information.
* Favorites.

### Administrator

* Dashboard for managing the application.
* Add and manage meals.
* Edit and delete meal information.
* Manage delivery drivers.
* Manage orders.

### Delivery Driver

* View assigned orders.
* View order and meal details.
* Update delivery status.
* View delivered orders.
